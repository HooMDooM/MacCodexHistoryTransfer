Mac Codex History Transfer 0.4.0

1. Установите и откройте приложение на обоих Mac в одной сети. Разрешите доступ к локальной сети.
2. Если приложение просит включить «Удалённый вход», нажмите «Включить» и разрешите доступ своему пользователю. Это нужно один раз.
3. Нажмите «Найти Mac», выберите второй Mac и нажмите «Подключить».
4. При первом подключении сравните код в окне с кодом внизу окна приложения на втором Mac и введите пароль пользователя второго Mac. Пароль не сохраняется.
5. Выберите направление и нажмите «Перенести». Codex закроется на обоих Mac, а прогресс в процентах будет виден на обоих.
6. После завершения откройте Codex на принимающем Mac.

Переносятся только чаты и история: sessions, archived_sessions, history.jsonl, session_index.jsonl, memories и базы state/thread_history/goals/memories. Вход в аккаунт, настройки, плагины и проекты остаются на своих Mac.

Резервная копия не создаётся: история на принимающем Mac заменяется целиком. Данные передаются потоком, без промежуточного архива, и проверяются по контрольной сумме и проверкой баз SQLite до замены. При ошибке история получателя не изменяется.

Требования: macOS 13+, одинаковые версии Codex и одинаковые домашние пути на обоих Mac, Python 3 (Command Line Tools). Свободное место на принимающем Mac — не меньше объёма переносимой истории.

Ключ подключения: ~/Library/Application Support/Codex Transfer/keys/id_ed25519. Он добавляется в ~/.ssh/authorized_keys второго Mac с пометкой CodexTransfer; чтобы отозвать доступ, удалите эту строку.

Если перенос был прерван аварийно: убедитесь, что на обоих Mac нет процессов agent/transfer.py, затем удалите папку ~/Library/Application Support/Codex Transfer/lock. Если в папке operations есть journal.json со статусом prepared, исходные файлы истории находятся в ~/.codex-transfer-old-<операция>.

Приложение подписано локально (ad-hoc) без нотаризации. На втором Mac может понадобиться «Открыть всё равно» в настройках конфиденциальности.
